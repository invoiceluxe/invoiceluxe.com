Sending one PDF is easier than sending five. Merging lets you put an invoice, a timesheet and your receipts into a single file that is easy to read, store and forward.

## When merging helps

- **Invoice plus support:** the invoice, timesheet and receipts together
- **Application packets:** forms, ID copies and letters in one file
- **Month-end records:** all invoices for a month for your accountant
- **Contracts:** a main agreement plus its attachments

## How to merge PDFs in your browser

1. **Open the merge tool.** Use a tool that works in the browser, so you do not need to install anything.
2. **Add your files.** Select the PDFs from your device.
3. **Put them in the right order.** Drag the files or use the move controls.
4. **Merge.** Click the merge button.
5. **Download the result** and check every page before you send it.

## Tips for a clean result

1. **Order matters.** Put the invoice first, then supporting documents.
2. **Name the file well.** For example, "Invoice-1042-Acme-Dec-2026.pdf". See [how to number invoices](/blog/how-to-number-invoices/).
3. **Check the page size and orientation.** Mixed sizes can look odd.
4. **Keep file size reasonable.** Many email systems limit attachments to around 20 to 25 MB.
5. **Look for sensitive data.** Merging combines everything, so check that no private page slipped in.

## Privacy

Be careful with tools that upload your files to a server. Invoices and receipts contain names, addresses and amounts. Use a tool that processes files in your browser when you can.

## Examples of the right order

| Purpose | Suggested order |
|---|---|
| Invoice package | Invoice, timesheet, receipts |
| Expense claim | Summary page, receipts in date order |
| Job application | Cover letter, resume, references |
| Contract | Main agreement, schedules, signed pages |

Put the most important document first, because many readers only open the first page.

## Problems and fixes

- **A password-protected file will not merge.** Remove the password first, if you have the right to do so.
- **The result is too large.** Compress the images, or merge fewer files.
- **A page is upside down.** Rotate it in the original file, then merge again.
- **Pages have different sizes.** Use the same paper size when you scan or export.

## Name the merged file

Choose a name that explains what is inside and when it was made, such as "Expense-claim-2026-11.pdf". If you send it to several people, include a version or date.

## Keep the originals

Merging creates a new file. Keep the original files in case you need to change one of them later. Store the merged file next to them.

## When not to merge

Do not merge files that need different permissions or different recipients. For example, keep a confidential contract separate from a public brochure. Send each person only what they need.

## FAQ

### How do I combine PDF files for free?

Use an online merge tool: add your files, set the order, merge and download the result.

### Can I change the order of pages after merging?

Set the order before merging. If you made a mistake, merge again with the files in the right order.

### Does merging reduce quality?

Merging normally keeps the original quality. Compressing is a separate step.

### Is it safe to merge confidential documents online?

It is safer with a tool that works locally in your browser. Avoid uploading sensitive files to unknown sites.

### Is there a limit to how many PDFs I can merge?

Browser-based tools can handle many files, but very large files may slow your device. Merge in smaller batches if needed.

### Will merging remove my signature?

Merging usually keeps the pages as they are, but digital signature features may not survive. Sign after merging if you need a valid digital signature.
