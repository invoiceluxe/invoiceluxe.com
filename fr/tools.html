Outils métier gratuits pour freelances et PME – France & monde

Invoice Luxe est une Progressive Web App (PWA) 100 % gratuite pour freelances, auto-entrepreneurs et petites entreprises. Aucun outil n'exige d'inscription, d'abonnement ou de frais cachés. Tout fonctionne dans votre navigateur ; vous pouvez aussi installer l'app sur iPhone, Android ou ordinateur et travailler hors ligne. Épinglez vos outils favoris en haut de cette page.

Pourquoi choisir les outils Invoice Luxe ?

  • Totalement gratuit : générateur de factures, devis, signature PDF, calculateur TVA, analyse fiscale, journal d'heures et plus – gratuit pour toujours.
  • Sans inscription : démarrez immédiatement. Vos données restent sur votre appareil.
  • Progressive Web App : ajoutez à l'écran d'accueil iOS ou Android, ouvrez comme une app native, travaillez hors ligne.
  • Mobile et desktop : iPhone, iPad, Android, Windows, Mac – la même expérience.
  • Favoris : marquez un outil d'une étoile pour l'épingler en haut.
  • Multilingue : français, anglais, allemand, néerlandais, italien et plus.

Outils gratuits populaires

Générateur de factures : factures PDF pro. Devis : devis et estimations. Moteur PDF : créer, signer, image vers PDF. Calculateur TVA : ajouter ou retirer la TVA. Analyse fiscale : suivre TVA et bénéfice. Journal d'heures : heures facturables.

Ajouter Invoice Luxe à l'écran d'accueil

iPhone / iPad (Safari) : Partager → Sur l'écran d'accueil.

Android (Chrome) : Menu → Installer l'application.

Choisissez un outil et commencez – absolument gratuit.

Zum Accueilbildschirm hinzufügen

Installieren Sie Invoice Luxe wie eine native App. Funktioniert offline. Kein App Store erforderlich.

phone_iphone iPhone / iPad (iOS)

  1. Öffnen Sie invoiceluxe.com im Safari-Browser.
  2. Tippen Sie auf die Teilen-Schaltfläche (Quadrat mit Pfeil nach oben).
  3. Scrollen Sie nach unten und tippen Sie auf Zum Accueilbildschirm hinzufügen.
  4. Bestätigen Sie den Namen und tippen Sie dann auf Hinzufügen.

android Android (Chrome)

  1. Öffnen Sie invoiceluxe.com in Chrome.
  2. Tippen Sie auf das Menü (drei Punkte) → App installieren oder Zum Accueilbildschirm hinzufügen.
  3. Bestätigen Sie. Das Symbol erscheint auf Ihrem Accueilbildschirm.

computer Desktop (Chrome / Edge)

  1. Achten Sie auf das Installationssymbol in der Adressleiste oder nutzen Sie das Browsermenü.
  2. Wählen Sie Invoice Luxe installieren und bestätigen Sie.

Auf Android installieren

Fügen Sie Invoice Luxe zu Ihrem Accueilbildschirm hinzu. Kostenlos, kein Play Store erforderlich. Funktioniert offline.

android Chrome (empfohlen)

  1. Öffnen Sie invoiceluxe.com im Chrome-Browser auf Ihrem Android-Handy.
  2. Tippen Sie auf das Menü (drei Punkte) in der oberen rechten Ecke.
  3. Tippen Sie auf App installieren oder Zum Accueilbildschirm hinzufügen.
  4. Bestätigen Sie. Das Invoice Luxe-Symbol erscheint auf Ihrem Accueilbildschirm.
  5. Öffnen Sie es jederzeit – es funktioniert wie eine normale App und kann offline arbeiten.

Tipp

  1. Manche Handys zeigen unten ein Banner: „Invoice Luxe zum Accueilbildschirm hinzufügen“. Sie können auch dieses verwenden.
  2. Wenn Sie Installieren nicht sehen, stellen Sie sicher, dass Sie Chrome verwenden und die Seite über HTTPS geladen ist.

Zum Accueilbildschirm auf iOS hinzufügen

Installieren Sie Invoice Luxe auf iPhone oder iPad. Verwenden Sie Safari – andere Browser auf iOS unterstützen dies nicht auf die gleiche Weise.

phone_iphone iPhone / iPad (Safari)

  1. Öffnen Sie invoiceluxe.com im Safari-Browser (nicht Chrome oder Firefox).
  2. Tippen Sie auf die Teilen-Schaltfläche am unteren Bildschirmrand (Quadrat mit Pfeil nach oben).
  3. Scrollen Sie im Teilen-Menü und tippen Sie auf Zum Accueilbildschirm hinzufügen.
  4. Sie können den Namen bei Bedarf ändern und dann auf Hinzufügen tippen.
  5. Das Invoice Luxe-Symbol erscheint auf Ihrem Accueilbildschirm. Öffnen Sie es wie jede andere App.

Tipp

  1. Auf dem iPad befindet sich die Teilen-Schaltfläche oft in der oberen Symbolleiste.
  2. Nach dem Hinzufügen kann die App im Vollbild geöffnet werden und viele Funktionen funktionieren offline.

So nutzen Sie die Outils-Seite

Kurzanleitung zu Favoriten, Kategorien und Installation der App.

1. Nach Kategorie stöbern

  1. Outils sind gruppiert: Facturation & clients, PDF & Bild, Fiscalité & finance, Temps & planning, Utilitaires.
  2. Tippen Sie auf eine Karte, um das jeweilige Tool zu öffnen. Keine Anmeldung erforderlich.

2. Favoriten oben anheften

  1. Tippen Sie auf den Stern einer Tool-Karte, um es zu Ihren Favoriten hinzuzufügen.
  2. Favorisierte Outils bleiben oben auf dieser Seite angeheftet.
  3. Tippen Sie erneut auf den Stern, um es zu entfernen. Ihre Auswahl wird nur auf diesem Gerät gespeichert.

3. Zum Accueilbildschirm hinzufügen

  1. Nutzen Sie die Leiste oben auf dieser Seite oder öffnen Sie das Profil (unten rechts) für die Schritt-für-Schritt-Anleitung für Android und iOS.
  2. Nach der Installation öffnen Sie Invoice Luxe wie eine normale App und arbeiten Sie offline, wo unterstützt.

4. Dunkel- / Hell-Modus

  1. Öffnen Sie das Profil (untere rechte Navigation) und nutzen Sie den Dunkel-/Hell-Schalter.
  2. Die Einstellung wird auf Ihrem Gerät gespeichert.
