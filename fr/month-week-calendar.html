COMMENT UTILISER

1

Sélectionner un jour — Appuyez sur un jour du calendrier. Le jour sélectionné sera mis en évidence avec une bordure dorée.

2

Écrire votre note — Saisissez votre tâche, rappel ou rendez-vous dans la zone de texte sous le calendrier.

3

Enregistrer — Appuyez sur Enregistrer. Les jours avec des notes deviendront bleus pour les repérer facilement.

4

Activer les notifications — Appuyez sur le bouton Alertes pour autoriser les notifications du navigateur.

5

Supprimer une note — Sélectionnez le jour et appuyez sur Supprimer pour effacer la note définitivement.
